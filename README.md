# Python ile Ok Şekilleri Oluşturma

## Proje Hakkında
Bu projede Python programlama dilinde `print()` komutu kullanılarak farklı boyutlarda ok şekilleri oluşturulmuştur. Şekiller tek tırnak işaretleri ve boşluklarla biçimlendirilmiştir.

## Projenin Amacı
- `print()` komutunun kullanımını öğrenmek.
- Tırnak işaretleri ve boşluklarla çıktı biçimlendirmek.
- Küçük ve büyük ok şekilleri oluşturmak.
- İki ok şeklini yan yana yazdırmak.

## Proje İçeriği
1. Küçük boyutlu tek ok
2. İki kat büyüklüğünde tek ok
3. İki büyük okun yan yana gösterimi

## Kullanılan Teknolojiler
- Python 3
- Python IDLE

## Nasıl Çalıştırılır?
1. Python IDLE programını açın.
2. `File > Open` seçeneğiyle Python dosyasını açın.
3. `F5` tuşuna basarak kodu çalıştırın.
4. Oluşturulan ok şekillerini IDLE Shell ekranında görüntüleyin.

## Öğrenilenler
Bu uygulama sayesinde `print()` komutuyla metin tabanlı şekiller oluşturma, karakterlerin konumlarını boşluklarla ayarlama ve çıktı biçimlendirme konularında deneyim kazanılmıştır.
